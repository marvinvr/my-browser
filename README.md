# myBrowser

An opinionated, native macOS browser built on WebKit. Vertical sidebar with pinned sites, nested folders and Spaces (each with its own profile), iCloud sync, Safari web extensions, and import from Chrome and Arc.

Work in progress.

## Install

Download the latest release from <https://github.com/marvinvr/my-browser/releases/latest>. Open the disk image and drag myBrowser to Applications. Requires macOS 26 or later.

Updates arrive through [Sparkle](https://sparkle-project.org). The app checks once a day. **Check for Updates…** in the myBrowser menu checks immediately.
